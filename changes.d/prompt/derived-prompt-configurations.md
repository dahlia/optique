 -  Added `derivePromptConfig()`, which derives a prompt configuration from
    one or more dependency source values.  The resolver may return the
    configuration synchronously or asynchronously, runs only at the real
    prompt fallback after the named sources resolve, and can distinguish
    published values from its own declared defaults.  Static prompt
    configurations keep working unchanged, and every wrapper generated by
    `createPromptAdapter()` accepts the derived form.  [[#869], [#872]]
